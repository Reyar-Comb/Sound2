# 建筑平面模式：最终验证

2026-11-14，Unity 6000.6.6f1，BaiYu-Test 已切换到新增的“建筑平面 · 八层探险”模式。原手工布局、种子程序化及独立房间回环生成器保留。

建筑模板按种子小幅改变尺寸，功能关系保持稳定。相邻室内房间通过隔墙、门洞和 2.6 米净高门楣连接；公共交通保留回环，私密房间允许单入口。超市营业区开放，后场保留隔墙。墙面装饰避开门洞，新增床头柜、衣柜、洗手池、马桶、洗衣机和果蔬台已接入道具工具。

最终验证结果：

- Edit：49 项通过，房间连通、回环、无竖井、网格资源及停靠对齐。
- Architecture：35 项通过，分区不重叠、共墙门洞物理开放、家具足迹不越界、床位／购物车／墙饰数量及 Boss 布局。
- Seeds：5 个种子 × 7 个建筑层，35 个有效且不同的平面；编辑器存在新模式选项。
- Play：109 项通过，家具存在时全房间导航可达、真实角色穿门、七次升降抵达 F8、持物按按钮和货物运输、永久开门、轿厢隐藏楼层 HUD。

修复了持久化 Mesh 仅 CopySerialized 后 GPU 仍显示旧几何的问题，改为写入 Mesh 通道，保留网格子资源身份并立即刷新画面。共墙门洞因编辑而错位时，编辑器提示修复并保留最后有效几何。

新增报告：`Logs/EightFloorAdventure/architecture-checks.txt`、`seed-checks.txt`、`snow-preservation.txt`。八层俯视图、电梯截图及原三类测试报告已更新。视觉复查：建筑空间可读性 4/5，新增模式与轿厢 UI 4/5，其余沿用下述风格评分。仍使用现有简化家具及强化怪物玩法，没有新增独立 Boss 战斗阶段或击杀结算。

# 前一版独立房间回环模式验证（历史记录）

2026-11-14，Unity 6000.6.6f1，场景 `Assets/Scenes/BaiYu-Test.unity`。

## 结果

- 编译：0 错误、0 警告。
- Edit：49 项通过，0 失败。
- Play：102 项通过，0 失败；真实角色穿门与七次连续升降，最终到达 F8。
- Persistence：5 项通过，0 失败；房间撤销、几何重建、完整导出、重新打开、Prefab 关联均通过。
- 运行控制台：0 错误、0 异常。
- 每次 Play 均通过 `Time.frameCount` 变化验证，截图之前等待实际渲染帧。

关键覆盖：每个房间至少两条通道、多个独立回环、家具存在时全房间导航可达、七个停靠点垂直对齐、无竖井、仅上行、不得重放换层、到站门永久开启、正常恢复控制、持物通过实际交互焦点启动电梯、手持及散落物品跨层、退出轿厢后地面支撑。

详细结果：`Logs/EightFloorAdventure/edit-checks.txt`、`play-checks.txt`、`persistence-checks.txt`。

## 最终内容

8 层，96 个房间，140 条走廊（含电梯门廊），7 部电梯，695 个家具／道具实例。所有家具保留 Prefab 关联。地图尺寸约 70 × 90 米／层，按主题改变房间尺度、横向连接、通道宽度及家具组合。

生成采用主题预设的连通骨架和确定性参数；种子改变房间尺寸与雪林道具朝向。它不是每次开局完全打乱房间关系的无限地牢。生成结果在场景中持久化，支持继续手工编辑。

新增床、沙发、工作台、超市货架、收银台、病床、隔帘、雪松、雪石、长椅和立柱 Prefab，已接入原道具下拉列表。Boss 层使用现有强化怪物逻辑，没有引入独立 Boss 战阶段或击杀结算。
