# BaiYu-Test：八层上行探险

打开 `Assets/Scenes/BaiYu-Test.unity`。沿用 SONICSPACE 开场菜单、黑底声纳点阵、玩家交互和生命系统；探索从 **F1** 开始，依次进入家、学校、超市、餐厅、图书馆、医院、雪林和 Boss 房，在 F8 结束楼层链。

本场景已替换原来的无限种子下落流程：没有竖井，没有跌落换层。普通行走、跳跃和物品仍有重力。旧 `LevelMap` 和 `BaiYuTestScene` 保留给原示例场景使用，不再挂在 BaiYu-Test 中。

## 电梯

- 七部独立电梯分别连接 1→2、2→3……7→8。不能跨层，不能下行，不能重新调用已经抵达的电梯。
- 外侧左键交互打开门；走入轿厢后，左键点击内侧按钮启动。玩家必须完全进入安全乘坐区。
- 关门 1 秒、实际升高 14 米（默认 5 秒）、开门 1 秒。运输期间保留环顾，暂时锁定移动和投放物品；到站后恢复。
- 上下端真实垂直对齐；角色和轿厢中物品连续移动。楼层编号在到达后更新一次。
- 到站后轿厢永久留在上层，轿厢门和上层门永久打开。下层门保持关闭，封闭井道防止坠落。
- 手持物品随玩家上行，放下后归属当前层。轿厢里的散落刚体在运输中固定，到站恢复原物理模式。
- 电梯使用白底黑边材质，独立于普通场景的声纳显影。材质在声纳合成后绘制，并使用实际深度遮挡。
- 轿厢内没有楼层数字牌，内侧按钮使用通用上行提示；进入轿厢时隐藏楼层 HUD，离开后恢复。门外保留目的层标识。
- 门口沿用现有空间嗡鸣提示；`motor` 留有录音接口，未绑定录音时不生成替代电机音效。

## 地图与关卡编辑器

当前使用新增的 **建筑平面 · 八层探险** 模式，共 101 个房间／功能区域、172 条门洞或通道、1139 个家具／道具实例。室内按建筑功能组织相邻房间、共墙门洞、内部隔墙、门楣和主次走廊。公共路线形成回环，卧室、衣帽间等允许单入口。超市营业区域采用开放分区，后场保留隔墙。雪林完整保留旧布局，移至第 7 层。

建筑尺寸按种子小幅变化，功能分区关系保持稳定；家具按房间用途和实际净尺寸成组排布。它是建筑模板驱动的确定性生成，不是随机打乱所有房间关系。

| 层 | 主题 | 主要内容 |
|---|---|---|
| 1 | 家 | 玄关、客厅、卧室、书房、厨房、餐厅、内庭；床、沙发、厨具、电视、闹钟 |
| 2 | 学校 | 教室、实验室、音乐室、办公室、阅览室、中庭；课桌椅、电脑、球、录音设备 |
| 3 | 超市 | 果蔬、冷藏、食品、日用品、收银与仓储；货架、商品、冰箱、购物车、收银台 |
| 4 | 餐厅 | 散座、包间、宴会厅、后厨、洗消、冷库；餐桌椅、杯具、餐铃、工作台 |
| 5 | 图书馆 | 分类书库、档案、自习、期刊与中央阅览厅；书架、阅览桌、台灯 |
| 6 | 医院 | 双侧病区、主走廊及疏散走廊；51 张病床、床头柜、隔帘、监护仪、候诊座位 |
| 7 | 雪林 | 原有松林、营地、石径、林心、巡林小屋；松树、雪石、长椅、收音机 |
| 8 | Boss 房 | 约 32 × 32 米中央对战大厅、四周环廊、七间双门追逐房；掩体与现有强化巡逻怪物 |

Boss 房目前接入现有怪物／扫描／闪电玩法，尚未新增独立 Boss 血条、战斗阶段或击杀通关规则。

打开 **Tools → Sound2 → 关卡编辑器**，选择 **建筑平面 · 八层探险**，使用 **探险楼层** 下拉框切换 1–8 层。原手工布局和种子程序化模式保留；切换生成模式本身不会替换地图，点击“按种子重建八层”才执行。生成结果是场景中持久化的 `LevelLayout`，可以继续编辑房间、走廊和 Props。

- **重新生成**：仅重建所选楼层几何，保留家具与电梯。
- **按种子重建八层**：使用确定性主题规则重新生成布局与家具，替换整个探险地图。执行前会将完整当前场景备份到 `Logs/AdventureBackups`。
- **保存当前场景**：保存全部八层布局及各自独立的网格子资源。
- **导出 .unity 场景**：在此地图内导出完整场景，包括全部楼层、电梯、玩家、菜单和家具，继续引用项目内的网格与 Prefab 资源。
- **电梯门廊**：用现有走廊连接房间，终端门洞保存在 `LevelLayout.doorways`。移动／缩放房间后起点跟随，电梯端保持固定。不要把家具放在门口和通道中央。
- **雪林**：`openSky` 使运行时顶面保持关闭；其余楼层正常封顶。
- **共墙门洞**：两端必须位于相邻房间的同一墙面位置。移动房间造成错位时会给出提示，并保留最后一次有效几何。可以重新贴合房间，或取消“共墙门洞”改为普通走廊。
- **用途和开放分区**：房间属性可编辑用途；“开放分区（无隔墙）”用于超市分区等；“保留房间隔墙”在楼层生成设置中控制。
- **家具**：入口停放区、收银区及营业区共 30 辆购物车；病床成组靠墙排列并保留中央通道。壁画、镜子、橱柜按墙面朝向吸附，避让门洞；新增床头柜、衣柜、洗手池、马桶、洗衣机、果蔬台均进入原道具列表。

独立生成入口：`Tools → Sound2 → 八层上行地图 → 建筑平面模式重建 BaiYu-Test`，或运行 `BuildEightFloorAdventure.Architecture`。旧 `重构 BaiYu-Test` 菜单仍生成独立房间与回环走廊版本。两种模式共用 `AdventureMapBuilder`、`LevelBuilder` 和 `LevelGeometry`，只作用于已打开的 BaiYu-Test。

## 运行时管理

`EightFloorAdventure` 维护八个 `AdventureFloor` 与七部 `OneWayElevator`。初始仅激活 F1；乘梯前准备目的层，到站后停用旧层。场景实例和状态保留，不反复生成物品。仅当前层的导航、巡逻怪物和闪电处于活动状态。

`PlayerFloorProgression` 自动识别此地图，起始楼层为 1，并拒绝所有竖井下降。其他场景仍走原有路径。`BaiYuTestFloorProgression.asset` 包含八层中文引导。

新增家具 Prefab 位于 `Assets/Prefabs/Adventure`，可以继续用现有道具工具摆放。已有家具和可交互物品继续保留原 Prefab 关联。

## 验证与视觉约定

运行入口 `AgentScripts/VerifyEightFloorAdventure.cs`：

- `Edit`：八层七梯、无竖井、房间连通和度数、回环数、网格资源隔离、交互物品、停靠对齐。
- `Play`：开场进入 F1、家具摆放后的全房间导航、真实角色穿门、连续七次升降、楼层计数去重、拒绝逆行、到站门保持打开、退出轿厢后有地面支撑。
- `Overviews`：生成八层俯视图。报告和截图位于 `Logs/EightFloorAdventure`。

视觉延续已有项目约定：普通世界为黑色、声波白点、怪物红／闪电蓝；电梯按照需求使用白纸底与黑色结构线。编辑预览沿用蓝灰地面和亮色家具，不把预览颜色带入游戏。参考了 Unity CLI 的 playmode-verification-loop、craft-game-floors 的 art-direction / visual-scorecard，以及 UI Toolkit 的 common-issues / uss-guide；不应用与现有声纳风格冲突的默认灯光和调色方案。
