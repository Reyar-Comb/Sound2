# BaiYu-Test 全系统测试场景

打开 `Assets/Scenes/BaiYu-Test.unity` 并 Play。场景使用运行时种子地图，因此编辑模式只保留玩家、地图配置和系统入口，房间与玩法对象在运行时生成。项目设置和包配置保持不变。

进入 Play 后先播放白场、律动声纹与 SONICSPACE 逐字漂浮的点阵开场；点击“开始”播放 2.6 秒中心塌陷过渡，再恢复 F0 的玩家操作和字幕。菜单详见 [StartMenu.md](StartMenu.md)。

## 运行流程

从 F0 出发，层数就是地图种子。经最远房间的竖井真实下落后进入 F1、F2……，更新楼层标签、字幕、声纳范围和余像，并逐层增加怪物速度与闪电伤害。地图仍按原有上限增长，并只保留上一层、当前层和下一层。

每层都包含：

- 现有玩家控制、重力、轻微相机晃动、中心白点和柔和交互圈。
- 每层入口两个普通球，其余房间各一个；普通球统一支持鼠标／E 拾取、居中持物、投掷和碰撞声波。
- 可拿起、抛出和放下的八面棱晶；不再收集或计入资源。
- 6 + 3 × 有效楼层数枚金币；现在也是物理道具，靠近不会消失或入账。
- 一个不可见巡逻怪物，具有房间巡逻路径、脚步／碰撞听觉、红色扫描和闪电避让。
- 一个体积点云球状闪电，自动在平静／活跃状态间切换，保留蓝色扫描、游荡和生命值伤害；前后层点均可见，实体墙仍遮挡它。
- 出生房间的方块改为普通可搬运道具，不再控制闪电。
- 竖井上方的低音空间声源，用声音提示出口位置。
- 白、红、蓝色共用声波场，金币为稀疏白色点阵并从中心向外显现；脚步、距离／密度衰减、遮挡与点阵 UI 避让。
- SECONDERSIGN 字体与现有中文回退、中文楼层字幕和生命 HUD；移除背包、金币及资源计数，开发面板默认关闭。

BaiYuTestScene 按 FloorChanged 事件建立当前层的导航和玩法内容，上一层的 AI、波源及闪电停用。导航在生成几何之后建立，避免空地图烘焙。球状闪电新增可选的相对出生高度模式，此场景开启；原 prefab 和原场景继续使用绝对高度。

## 操作和测试入口

WASD 移动，鼠标转视角；鼠标左键拿起／投掷，同时触发玩家声波，E 保留拾取／投掷；右键放下已持有的物品，不施加投掷冲量。持物随转镜头产生柔和惯性并自动归中，贴墙收回。Enter 单独发波，F 切换自动发波；1/2 面／轮廓点，3/4 近距离／声波显影，5 衰减，6 脚步波，H 竖井嗡鸣，F1 显示／隐藏声纳调试面板。Esc/Tab 释放鼠标，点击游戏画面重新捕获。

运行时选中 `BaiYu-Test Systems`，组件右键菜单提供：

- `Test: move above current floor shaft`：只移动到本层竖井上方，仍由重力和真实越界检测完成下楼。
- `Test: restore player health`：恢复 HP。

HP 耗尽沿用现有生命系统提示；项目尚未定义死亡／复活流程，此测试场景没有自行新增规则。Steam Audio 使用现有空间声源与监听器，不加载其他场景的静态声学烘焙数据；程序化地图的可视声波和 AI 听觉使用实际 Collider。

## 验证

`AgentScripts/VerifyBaiYuTest.cs` 在本场景 Play 下运行，检查 F0 到 F3 的真实竖井下落、着地、每层导航、物理道具、地下闪电高度／伤害、旧层清理、字体和 UI 点阵遮挡。本轮新增测试与实际结果见 [PhysicalItems.md](PhysicalItems.md)。

场景创建入口为 `AgentScripts/ConfigureBaiYuTest.cs`，目标场景已存在时拒绝覆盖，保护后续手动编辑。独立楼层文案／难度配置为 `Assets/Resources/BaiYuTestFloorProgression.asset`。

## 重复拾取与竖井防连掉修复

持球时按实际球形 Collider 计算释放半径，并同步 Transform 与 Rigidbody 的持有姿态；靠墙时将球收回到墙前，防止手持模型插入墙体。投出跨层携带的球时归属当前有效楼层，避免恢复到已停用或已清理的旧楼层父节点。

新生成楼层保持原种子布局，必要时旋转整层，保证当前加载窗口内的出口竖井至少相隔 6m。每层入口有独立实体承接板；完成一次竖井越界后必须先在目标层落地，才重新允许进入下一层。如长帧或外部位置变更跳过承接面，会恢复到目标层的安全入口，并重置下落速度。

回归入口：

- `VerifyPickupAndShaftRegression.cs`：同层同一球连续拾取／投掷 8 次、贴墙持球、跨层释放、旧层清理、三次真实下降、未落地连层拒绝及穿过承接面后的恢复。
- `VerifyInteraction.cs`：加入真实鼠标同一物品三轮重复拾取／投掷。
- `VerifyShaftLayout.cs`：强制构造出口同列，验证旋转避让且种子布局不变；检查 256 个种子的安全入口与出口分离。


## 物体用途与中文交互反馈

普通球、八面棱晶、金币、方块统一使用 PickupItem。瞄准时显示中文拿起提示；持物时显示“左键 / E：抛出    右键：放下”。放下位置被挡住时保留手中物品并提示“空间不足，无法放下”。取消资源收集、钱包入账和闪电开关的旧提示。即时反馈会暂时打断楼层引导，结束后恢复原队列。

BaiYu-Test 的楼层初始引导、后续楼层文案、交互结果与状态文字已改为中文。保留 F0/F1 楼层标识和 WASD/E 等按键名称。字体使用当前 SECONDERSIGN 主字体与已有中文回退；新文案检查无缺字。

验证：`VerifySceneTargetClicks.cs` 在真实场景通过输入事件依次点击多个球、资源和方块；`VerifyChineseFeedback.cs` 检查即时反馈优先、原引导恢复和中文字符覆盖。自动化鼠标测试临时复制输入设置以接收后台测试设备，结束后恢复原设置，不写入项目配置。
