# 红色藤蔓区移动与声音

`MonsterVineAreaMotion` 配置起点、终点和移动速度，默认沿放置朝向移动 4 米、速度 1 米/秒、往返移动。起终点采用父物体局部坐标，整个关卡移动后路线会一起移动。Inspector 的「当前位置设为起点/终点」按钮和 Scene 端点手柄都支持撤销。关闭「往返移动」后，到达终点停止；速度 0 可暂停。

选中关卡编辑器中的红色藤蔓区，可直接编辑「藤蔓区移动」；未有移动组件的区域可按「添加起终点移动」。编辑状态不会自行移动，进入运行或重新激活时从起点出发。

组件监听同场景 `PlayerVitality.Died`：死亡立即回到起点、清除旧藤蔓、重置移动音效；死亡演出期间保持原地，复活后重新出发。区域移动是路径动画，不使用怪物寻路，也不被墙体阻挡，应由设计者将路线放在所需的危险区域。藤蔓仍只出现在范围内的真实表面，触碰致死规则不变。

红色藤蔓区复用 `MonsterAudioEmitter` 和 `Resources/MonsterAudio` 的三层空间音效：移动时的爬行声、低鸣、近距离吼叫，各层使用与怪物相同的音量、范围、淡入淡出和 Steam Audio 设置。静止时停止爬行声，低鸣与吼叫仍按距离播放。这里的声音不会发出 `GameplayNoise` 或扫描波，避免其他怪物被危险区自身声音持续吸引。

`RedVineArea.prefab` 已预装音效组件；旧场景的藤蔓区也会在运行时自动补齐音效。移动是可选组件，避免现有静态区域在升级后无意跳到默认端点。
