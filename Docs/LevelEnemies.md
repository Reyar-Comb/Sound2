# 关卡编辑器：敌人

在 `Tools > Sound2 > 关卡编辑器` 的「独立关卡」模式中选择布局，点击与房间工具同级的「放置敌人」，然后在 Scene 的本关地面点击。支持网格吸附、连续放置和 Esc 退出；坑洞、关卡外、墙壁及净空不足处不能放置。

每次放置创建一个独立的 `LevelEnemy` 出生锚点，内部的 `PatrolMonster` 使用现有听声调查、接触伤害和闪电避让逻辑，预装 `NavMeshAgent`、`MonsterScanEmitter`、`MonsterVines`、`MonsterAudioEmitter` 与默认音频配置。无需关联玩家或声呐；扫描组件运行时自动寻找它们。敌人没有可见模型，编辑期红色标记用于定位。

「敌人」列表支持选择、改名、位置、巡逻半径、巡逻/调查速度、听觉灵敏度和删除；Scene 支持拖动位置。巡逻路线从半径内的候选点与房间中心自动筛选，只有路径完整可达的点才会使用，路线固定在出生锚点下，不随敌人移动。狭小或孤立区域可能只有原地等待，但仍能听声调查。放置、移动、修改和删除支持 Unity Undo/Redo。

## 关卡统一攀爬高度

展开「敌人与寻路」，设置「最高攀爬台阶（米）」，点击「一键应用到本关全部敌人」。默认 `0.3` 米，范围 `0–1.8` 米。这是单级台阶允许的高度差，不是绝对海拔、连续楼梯总高度或爬墙能力；坡度上限保持已有的 45°。NavMesh 使用 0.1 米体素，边缘结果存在烘焙量化，应为临界障碍留余量。

本关共享一个 `RuntimePatrolNavigation`，收集整个 `LevelLayout` 下的静态碰撞体，包括固定道具。角色、触发器和 Rigidbody 动态物体不参与静态烘焙。应用时会将本关原有 `PatrolMonster` 绑定到此导航，并停用本关重复导航组件；其他关卡和全局导航不受影响。关卡参数是运行时烘焙的权威值，首次放置也会自动配置导航。

进入运行模式或重新激活关卡时自动烘焙，无需设计者手动生成 NavMesh。运行时移动的物体不会自动触发重新烘焙。保存场景、重新生成几何、导出 `.unity` 或 Prefab 均保留敌人和关卡内引用。

验证脚本：`AgentScripts/VerifyLevelEnemies.cs`，依次使用 `EditMode`、运行模式的 `Runtime`、退出运行后的 `Cleanup`。测试资源仅位于 `Assets/__EnemyPlacementVerification`，测试会拒绝覆盖已有同名目录。
