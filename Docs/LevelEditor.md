# 关卡编辑器

菜单：**Tools → Sound2 → 关卡编辑器**。

窗口新增“生成模式”：**手工布局**保持下述编辑方式；**种子程序化**使用楼层编号生成可复现的地图，并在下落时准备下一层。新模式示例为 `Assets/Scenes/SeededMapDemo.unity`，详见 [种子地图、层数与字幕](SeededMapAndSubtitles.md)。已有地图不会自动转换。

示例：`Assets/Scenes/LevelEditorDemo.unity`。双击场景后选中 `Editable Level`，在 Inspector 点击“打开关卡编辑器”。示例包含三个房间、直线/曲线走廊，以及房间内和走廊内各一个下落竖井。

空白编辑工作区：`Assets/Scenes/LevelEditorWorkspace.unity`。它和示例场景均独立于 `BlackBoxPointCloud.unity`。

## 绘制和修改

1. 点击“新建独立场景”，然后“俯视 / 框选全部”。新布局始终在独立场景中创建，不会添加到 BlackBoxPointCloud 等已有游戏场景。当前场景未保存时，Unity 会先显示保存对话框。Scene 视图使用正交俯视；鼠标滚轮缩放，Unity 常规视图操作仍可使用。
2. 选择“矩形房间”或“圆柱房间”，点击 Scene 放置中心。切换“选择 / 编辑”，点击对象标记或窗口列表；拖动黄色中心移动、红色/绿色尺寸手柄缩放，也可输入精确中心、宽长、直径和旋转角度。
3. “直线走廊”和“曲线走廊”均可连续点击添加多个控制点，**Enter 完成**（至少两点），**Backspace 撤回一点**，**Esc 取消**。直线走廊用直线逐段连接各点；曲线采用分段三次 Hermite 插值，经过所设控制点。选中后可拖动控制点、修改坐标，在任意两点间点“+”添加控制点，或删除中间点。
4. “净通行宽度”是走廊内部宽度，外墙向外增厚。全局“新走廊宽度”只影响新建走廊。
5. “连接端点”：先从列表选中已有走廊，选择连接起点或终点，再点击房间边缘。绿色圆圈显示候选边缘点。连接点以房间 ID 和沿边位置保存，房间平移、旋转、缩放后会跟随；连接处自动开墙。也可输入沿边位置或解除连接。
6. “方形竖井”：点击房间或走廊内部放置。选中后编辑边长、深度、旋转角度和中心。地板及地板碰撞体实际挖空，四面管壁向下延伸，底端敞开。坑与管壁必须完整在可行走区域内，不能相互重叠。
7. **Ctrl+Z / Ctrl+Y** 支持撤销/重做。网格吸附设为 `0` 可自由移动；默认 `0.5m`。生成设置可修改墙高、墙厚、地板厚度、圆形细分、曲线采样和材质。

编辑范围是同一 XZ 平面的单层布局；每个布局使用统一墙高。圆柱房间使用圆形截面，不是椭圆。房间与走廊相交时会合并为连续可行走区域，紧急回转或自交曲线也按轮廓并集处理。顶面按同一轮廓自动生成，底面位于墙高处，厚度沿用地板厚度；房间和走廊均封顶，地板竖井与竖井底端仍保持敞开。

## 道具放置

手工布局使用“放置道具”工具及“道具 / Props”下拉列表；列表显示简短中文名称，不再重复显示 Prefab 字段。Scene 中显示绿色线框预览，左键连续放置，Esc 返回选择模式。贴墙放置先切到“3D 检查”，指向墙体内侧。吸附范围包括当前布局的有效几何和 Props 下已有道具的碰撞面，因此可以把杯子、台灯、电脑放到桌面或书架上；不会吸附到其他布局或隐藏顶面。面板按钮自动换行，高度不足时整体滚动。

列表包含钟表、球、闹钟、玻璃杯、桌子、椅子、购物车、图书架、书桌、电脑、水杯、台灯、冰箱、灶台、垃圾桶、咖啡杯、陶瓷花瓶。闹钟可拾取并在首次拿起后延时快速响铃，与不可拾取的挂墙钟表是两个预制体；破坏阈值和计时配置见 `Docs/PhysicalItems.md`。

- 钟表按墙面法线转正并保持竖直，圆形房间同样适用；球按底部锚点落地，计算包含预制体缩放。
- “离表面距离”控制间隙；“面内旋转角度”控制钟表在墙上的旋转或地面道具的朝向。道具吸附采用实际表面命中点，不使用布局的 XZ 网格吸附。
- 实例统一存放在 `Editable Level/Props`，与 `Generated Geometry` 分开。重新生成不会删除实例或覆盖其参数。
- 对象列表包含道具。同类道具重复放置时使用 Unity 风格的数字后缀，例如 `Chair`、`Chair (1)`、`Chair (2)`。选中后通过 Unity 变换工具或 Inspector 调整位置、旋转、缩放、桌子尺寸、钟表速度等参数，关卡面板不重复提供这些字段。删除、放置及参数修改支持 Undo/Redo。
- 保存场景和导出均包含 Props，导出保留 Prefab 关联和实例参数覆盖。现有场景根部的独立道具需要先移到 Props 下才会随布局导出。
- 此版本保存固定放置位置；修改房间形状后不会自动重新定位已放置道具。种子程序化模式仍使用自己的运行时生成流程。

自定义道具可在 Prefab 根节点添加 `LevelProp`：选择 Floor/Wall，设置本地 `Surface Anchor`、默认间隙以及运行材质。墙面道具约定本地 +Z 朝外、+Y 朝上，锚点位于背面的贴墙位置；地面道具锚点位于底部。没有该组件时，工具按网格包围盒底部进行地面放置。`Gameplay Material` 非空时，仅在运行期间替换网格材质，停止后仍显示编辑材质。

## 钟表

`Assets/Prefabs/TickingClock.prefab` 由直径 1.2m 的厚圆环和两条长短不同的长方体指针组成，无 PickupItem、InteractableObject 或 Rigidbody，不可拾取。背面原点用于贴墙，前方 `Tick Origin` 用于发波，避免声源陷进墙或指针内部。

`TickingClock` 默认每 1 秒发生一次机械 tick：长针顺时针跳 30°，12 次完成一圈并让短针跳 30°；144 次完成短针一整圈。`Tick Interval` 控制速度，`Running` 控制暂停，`Initial Long Step` / `Initial Short Step` 控制运行开始时的位置（默认 12 点 / 3 点）。运行中修改速度不会重置指针。菜单阻止玩法时暂停计时。

每次 tick 调用同对象的 `SonarObjectEmitter.EmitNow()`；该发声组件的自动定时及快捷键关闭，防止重复发波。声波默认 8m、7m/s、余辉 0.7s；音频距离默认 12m。`SonarCueSource.Clip` 暂留空且 `Generate Default Ping` 关闭，不生成替代音频；以后绑定录音即可沿用现有空间音效输出。钟表编辑时亮色、运行时黑色，通过共享点云渲染显影。

`test.unity` 已在玩家前方墙上放置钟表，位置约 `(-4.30, 1.80, 2.985)`。验证脚本 `AgentScripts/VerifyClockProps.cs` 覆盖 144 次 tick、顺时针方向、逐次发波、空素材静音/录音接口、实际点云像素，以及贴墙/落地、撤销重做、重建、保存导出与 Prefab 关联。报告与截图位于 `Logs/ClockProps`。

## 编辑预览与游戏外观

- **编辑模式**：继续显示原有彩色地板、墙和竖井材质，`Generated Geometry/Ceiling` 保持禁用，方便俯视和选择内部对象。导出的场景重新打开后也使用这一状态。
- **运行模式**：`LevelLayout` 使用已配置的 `PureBlack` 材质替换地图表面，并启用顶面的网格和碰撞体。退出 Play 后恢复彩色敞顶预览，不修改原有预览材质资源。
- **点云**：导出玩家复用 `SphericalSonar`、`BlackBoxProximitySource`、共享 `SonarPulseField` 和 `BlackBoxPointCloudFeature`，没有另建 Shader。默认只由声波显影，近处持续显影仍关闭；脚步、落地及主动探测均沿用公共 Player 的逻辑。
- **手动加入玩家**：`Assets/Prefabs/Player.prefab` 的相机已显式配置完整点云组件、材质和共享波场，不必经过导出工具。手动拖入后运行，在 Game 视图按 Enter 或走动可显影；静止且没有声波时保持黑色，编辑模式仍显示亮色敞顶预览。场景内应只有一套活动玩家/相机。
- `BlackBoxPointCloudFeature` 只作用于运行时 Game 相机，不向编辑预览、Scene、Preview 或 Reflection 相机叠加点云。
- 顶面虽然在编辑时不启用，仍作为独立网格子资源持久化，因此打包运行也能正常封顶。额外内容应放在 `Generated Geometry` 之外，避免重新生成时被覆盖。

## 保存与继续编辑

- **保存当前场景**：保留场景中的其他内容；`LevelLayout` 组件保存布局参数，`Generated Geometry` 保存实际网格与 MeshCollider。
- **导出 .unity 场景**：生成独立场景，包含布局、地板/墙/顶面网格、碰撞、Props 下的道具、编辑照明和可选点云重力玩家。不会复制布局层级之外的其他游戏对象。导出过程不切换或覆盖当前场景。
- 网格保存在场景旁边的 `<场景名>_Geometry/Meshes.asset`。场景和该目录需一起提交或移动；Unity 中移动资源会保留 GUID 引用。
- 重新打开场景、选中 `Editable Level` 即可继续参数化编辑。网格子对象也是普通 Unity 对象，可以自行修改；**再次生成会覆盖 `Generated Geometry` 下的手动修改**，额外道具请放在该节点之外。
- Ctrl+S 保存已有场景时也会持久化新生成网格。无效的坑洞参数会在窗口中报告，预览保留上次有效结果；请修正后再使用窗口保存/导出。

## 下落玩家

导出时默认实例化 `Assets/Prefabs/Player.prefab`，启用重力并在相机上配置现有点云/声波组件。公共 Player 已默认开启重力，空格使用现有 Jump 输入起跳；角色可掉入坑洞，落地反馈沿用脚步组件。脚步/落地音频只播放显式绑定的录音，目前素材留空，不生成兜底音效。

导出会寻找避开坑洞、足够容纳玩家胶囊的地面出生点。关闭“导出时加入重力玩家”可生成仅包含关卡的场景。竖井底端敞开，未加入死亡/重生规则；可以在井下自行放置触发器或下一层关卡。新场景没有自动烘焙 Steam Audio 声学数据。

## 验证与实现

- `AgentScripts/VerifyLevelEditor.cs` 创建示例，检查门口通行、圆形入口、曲线地板连续性、两种下落坑、胶囊穿井、外墙双向碰撞、无效布局保护、Undo/Redo、保存重开、导出资源独立性。重复运行不会覆盖已有示例。
- 同脚本的 `VerifySaved` 可重复检查已保存示例，强制重新导入网格并比较布局与磁盘资源。`AgentScripts/ReviewLevelEditor.cs` 输出俯视/3D 预览，并在隔离的编辑模式测试中调用实际玩家重力更新，验证站立与下落；它不切换当前编辑场景进入 Play Mode。
- `AgentScripts/VerifyLevelPresentation.cs` 的 `Edit` 入口检查亮色敞顶预览、隐藏顶面持久化、碰撞、竖井开口及新导出重开；`Play` 入口检查运行时黑色封顶、顶面实际点云像素及连续三层真实下落。截图保存在 `Logs/LevelPresentation/`。
- `AgentScripts/ConfigureLevelPresentation.cs` 可通过 Unity 的重建/保存流程更新旧版手工场景；已更新 LevelEditorDemo、LevelEditorWorkspace 和 test，布局参数保留。
- 几何位于 `Assets/LevelEditor/Editor/LevelGeometry.cs`，以 0.0001m 量化处理二维轮廓，合并后挤出地板、墙体、顶面和空心竖井。
- 使用 [Clipper2 2.0.1](https://github.com/AngusJohnson/Clipper2/tree/Clipper2_2.0.1) 完成轮廓布尔运算、偏移和三角化；源码和许可证保存在 `Assets/LevelEditor/Editor/ThirdParty/Clipper2`，不进入玩家构建。
- 运行时只需要 `LevelLayout` 的外观切换、已保存的网格/材质、现有点云组件及正常碰撞系统，不依赖编辑器三角化或资源加载逻辑。
