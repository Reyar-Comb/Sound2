# 关卡编辑器

菜单：**Tools → Sound2 → 关卡编辑器**。

窗口新增“生成模式”：**手工布局**保持下述编辑方式；**种子程序化**使用楼层编号生成可复现的地图，并在下落时准备下一层。新模式示例为 `Assets/Scenes/SeededMapDemo.unity`，详见 [种子地图、层数与字幕](SeededMapAndSubtitles.md)。已有地图不会自动转换。

示例：`Assets/Scenes/LevelEditorDemo.unity`。双击场景后选中 `Editable Level`，在 Inspector 点击“打开关卡编辑器”。示例包含三个房间、直线/曲线走廊，以及房间内和走廊内各一个下落竖井。

空白编辑工作区：`Assets/Scenes/LevelEditorWorkspace.unity`。它和示例场景均独立于 `BlackBoxPointCloud.unity`。

## 绘制和修改

1. 点击“新建独立场景”，然后“俯视 / 框选全部”。新布局始终在独立场景中创建，不会添加到 BlackBoxPointCloud 等已有游戏场景。当前场景未保存时，Unity 会先显示保存对话框。Scene 视图使用正交俯视；鼠标滚轮缩放，Unity 常规视图操作仍可使用。
2. 选择“矩形房间”或“圆柱房间”，点击 Scene 放置中心。切换“选择 / 编辑”，点击对象标记或窗口列表；拖动黄色中心移动、红色/绿色尺寸手柄缩放，也可输入精确中心、宽长、直径和旋转角度。
3. “直线走廊”：点击起点、终点。“曲线走廊”：依次点击希望曲线经过的控制点，**Enter 完成**，**Backspace 撤回一点**，**Esc 取消**。曲线采用分段三次 Hermite 插值，经过所设控制点。选中后可拖动控制点、修改坐标，在任意两点间点“+”添加控制点，或删除中间点。
4. “净通行宽度”是走廊内部宽度，外墙向外增厚。全局“新走廊宽度”只影响新建走廊。
5. “连接端点”：先从列表选中已有走廊，选择连接起点或终点，再点击房间边缘。绿色圆圈显示候选边缘点。连接点以房间 ID 和沿边位置保存，房间平移、旋转、缩放后会跟随；连接处自动开墙。也可输入沿边位置或解除连接。
6. “方形竖井”：点击房间或走廊内部放置。选中后编辑边长、深度、旋转角度和中心。地板及地板碰撞体实际挖空，四面管壁向下延伸，底端敞开。坑与管壁必须完整在可行走区域内，不能相互重叠。
7. **Ctrl+Z / Ctrl+Y** 支持撤销/重做。网格吸附设为 `0` 可自由移动；默认 `0.5m`。生成设置可修改墙高、墙厚、地板厚度、圆形细分、曲线采样和材质。

编辑范围是同一 XZ 平面的单层布局；每个布局使用统一墙高。圆柱房间使用圆形截面，不是椭圆。房间与走廊相交时会合并为连续可行走区域，紧急回转或自交曲线也按轮廓并集处理。当前不生成屋顶。

## 保存与继续编辑

- **保存当前场景**：保留场景中的其他内容；`LevelLayout` 组件保存布局参数，`Generated Geometry` 保存实际网格与 MeshCollider。
- **导出 .unity 场景**：生成独立场景，包含布局、网格、碰撞、照明和可选重力玩家。导出的是当前布局，不会复制原场景中的其他游戏对象。导出过程不切换或覆盖当前场景。
- 网格保存在场景旁边的 `<场景名>_Geometry/Meshes.asset`。场景和该目录需一起提交或移动；Unity 中移动资源会保留 GUID 引用。
- 重新打开场景、选中 `Editable Level` 即可继续参数化编辑。网格子对象也是普通 Unity 对象，可以自行修改；**再次生成会覆盖 `Generated Geometry` 下的手动修改**，额外道具请放在该节点之外。
- Ctrl+S 保存已有场景时也会持久化新生成网格。无效的坑洞参数会在窗口中报告，预览保留上次有效结果；请修正后再使用窗口保存/导出。

## 下落玩家

导出时默认实例化 `Assets/Prefabs/Player.prefab`，并仅在该场景实例开启 `PlayerController.useGravity`。该模式下自动受重力作用，不使用原自由升降输入，因此能掉入坑洞。原玩家预制体和旧场景的 `useGravity` 默认保持关闭。

导出会寻找避开坑洞、足够容纳玩家胶囊的地面出生点。关闭“导出时加入重力玩家”可生成仅包含关卡的场景。竖井底端敞开，未加入死亡/重生规则；可以在井下自行放置触发器或下一层关卡。新场景没有自动烘焙 Steam Audio 声学数据。

## 验证与实现

- `AgentScripts/VerifyLevelEditor.cs` 创建示例，检查门口通行、圆形入口、曲线地板连续性、两种下落坑、胶囊穿井、外墙双向碰撞、无效布局保护、Undo/Redo、保存重开、导出资源独立性。重复运行不会覆盖已有示例。
- 同脚本的 `VerifySaved` 可重复检查已保存示例，强制重新导入网格并比较布局与磁盘资源。`AgentScripts/ReviewLevelEditor.cs` 输出俯视/3D 预览，并在隔离的编辑模式测试中调用实际玩家重力更新，验证站立与下落；它不切换当前编辑场景进入 Play Mode。
- 几何位于 `Assets/LevelEditor/Editor/LevelGeometry.cs`，以 0.0001m 量化处理二维轮廓，合并后挤出地板、墙体和空心竖井。
- 使用 [Clipper2 2.0.1](https://github.com/AngusJohnson/Clipper2/tree/Clipper2_2.0.1) 完成轮廓布尔运算、偏移和三角化；源码和许可证保存在 `Assets/LevelEditor/Editor/ThirdParty/Clipper2`，不进入玩家构建。
- 运行时只需要 `LevelLayout` 数据、已保存的网格/材质及正常碰撞系统，不依赖编辑器生成逻辑。
